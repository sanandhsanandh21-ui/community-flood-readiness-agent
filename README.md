
# FloodReady Neighbourhood Copilot 🌧️

A community-first agent for flood preparedness.

## Features

- Household preparedness checklist
- Personalized preparation recommendations
- Flood scenario rehearsals
- Community help requests and offers
- Rule-based matching of non-emergency assistance
- Human review of community reports

## Technology

- Python
- Streamlit
- GitHub

## How to run

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the app:

```bash
streamlit run app.py
```

## Safety

This is an educational prototype. It does not provide
live flood warnings, flood predictions, emergency dispatch,
or verified evacuation routes.

Always follow official local emergency instructions.
